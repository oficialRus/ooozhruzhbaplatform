# ООО Жрушба — Платформа управления предприятием

Авторская ERP-система для управления производственными процессами.

## Модули системы

| # | Модуль | Описание |
|---|--------|----------|
| 1 | Приемка заказов | Создание, редактирование и отслеживание заказов |
| 2 | Сваривание | Контроль производственного процесса |
| 3 | Учет материалов | Складской учет материалов и комплектующих |
| 4 | Фасовка | Управление процессом фасовки |
| 5 | Отгрузка и накладные | Формирование накладных, контроль доставки |
| 6 | Оплата и дебиторка | Учет оплат и дебиторской задолженности |
| 7 | Рекламации | Работа с претензиями клиентов |

## Технологический стек

- **Backend**: Go (Golang)
- **Frontend**: React + TypeScript + Vite + TailwindCSS v4
- **Иконки**: Lucide React
- **Роутинг**: React Router v7

## Структура проекта

```
ooozhruzhbaplatform/
├── backend/                    # Go-бэкенд
│   ├── cmd/server/             # Точка входа
│   └── internal/
│       ├── handlers/           # HTTP-обработчики
│       ├── models/             # Модели данных
│       ├── middleware/         # Middleware (авторизация)
│       └── database/           # Работа с БД
├── frontend/                   # React-фронтенд
│   └── src/
│       ├── components/
│       │   ├── layout/         # Sidebar, Header, AppLayout
│       │   └── ui/             # Переиспользуемые UI-компоненты
│       ├── config/             # Конфигурация модулей
│       ├── context/            # React Context (авторизация)
│       ├── mocks/              # Мок-данные для разработки
│       ├── pages/
│       │   ├── auth/           # Страница входа
│       │   ├── dashboard/      # Главная / дашборд
│       │   ├── orders/         # Приемка заказов
│       │   ├── production/     # Сваривание
│       │   ├── materials/      # Учет материалов
│       │   ├── packaging/      # Фасовка
│       │   ├── shipping/       # Отгрузка и накладные
│       │   ├── payments/       # Оплата и дебиторка
│       │   └── claims/         # Рекламации
│       ├── router/             # Роутинг и защита маршрутов
│       └── types/              # TypeScript-типы
└── README.md
```

## Запуск

### Frontend
```bash
cd frontend
npm install
npm run dev
```
Откроется на http://localhost:3000
